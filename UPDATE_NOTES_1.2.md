# Chess Coach 1.2 — visual/system update

## Дизайн
- Новый визуальный язык по референсам: чёрный grid-background, кислотно-лаймовый system accent, пиксельная типографика и modular UI.
- Главное меню остаётся сверху и стало компактнее.
- Добавлены системные индикаторы, page index, bitmap/pixel accents, grid panels и более жёсткая геометрия.
- Игровая зона теперь выглядит как отдельный terminal/game module.

## Игра
- Явный выбор стороны: Белые / Чёрные.
- При выборе Чёрных Stockfish автоматически делает первый ход белыми.
- При выборе Белых первый ход делает пользователь, так как белые ходят первыми по правилам шахмат.
- После хода пользователя движок отвечает автоматически.
- Отдельный индикатор показывает, чей сейчас ход.

## Live Coach
- Белые / Чёрные теперь обозначают ориентацию доски и сторону, с позиции которой пользователь смотрит партию.
- Независимо от выбранной стороны пользователь вручную вводит ходы ОБОИХ игроков.
- Никаких автоматических ходов движка в Live Coach нет.
- В интерфейсе добавлено постоянное пояснение этого режима.

## API
- `player_side` добавлен как необязательное поле coach analysis request для совместимости с новым frontend.
