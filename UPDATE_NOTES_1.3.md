# Chess Coach 1.3 — interactive/open-data update

## Что изменено
- Coach хранит историю ходов и умеет распознавать риск троекратного повторения, пата и 50-ходового правила.
- В выигранной/не проигранной позиции Coach и бот фильтруют добровольные ничейные продолжения, если есть нормальная альтернатива.
- Русская нотация ходов по умолчанию (`Конь → e5+`) + переключатель SAN (`Ne5+`).
- Live Coach: выбранная сторона — только твоя сторона/ориентация, все ходы обеих сторон вводятся вручную.
- Дебюты: вместо локальных 68 записей backend при запуске загружает полный открытый ECO-каталог `lichess-org/chess-openings` (CC0), строит UCI-линии и отдаёт их в интерфейс. Если GitHub временно недоступен, остаётся локальный fallback.
- У каждого дебюта появилась интерактивная тренировка основной линии на доске с выбором белых/чёрных и подсказками.
- Уроки полностью переведены из текстового формата в board-first формат: один урок = серия из 5 реальных задач.
- Добавлены десятки интерактивных тем: маты, вилки, связки, рентген, отвлечение, уничтожение защитника, жертвы, защита, эндшпили, превращения и т.д.
- Тренажёры теперь подгружают новые задачи из Lichess Puzzle API, а не ограничиваются несколькими статичными FEN.
- У каждой задачи 4 уровня подсказок: идея → исходное поле → целевое поле → точный ход на русском.

## Открытые источники
- `lichess-org/chess-openings`: каталог шахматных дебютов, CC0 / public domain.
- Lichess puzzle collection/API: шахматные задачи из публичной базы Lichess; сама коллекция задач опубликована как public domain.

Приложение не копирует учебные статьи сторонних сайтов. Оно использует открытые фактические данные (позиции, линии, названия дебютов) и собственные русские объяснения/интерфейс.
