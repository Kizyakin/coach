# Chess Coach 1.4 — Master Games Coach

## Что изменилось

- Добавлена база из **45 выбранных великих и современных игроков** с профилями стиля.
- Добавлен `Master Games Engine`: Coach ищет похожие структуры в заранее собранной библиотеке мастерских партий и выводит типовые планы, а не копирует ход из другой позиции.
- Coach теперь ранжирует варианты по новой логике:
  1. самый быстрый форсированный мат;
  2. при равном мате — вариант с меньшей материальной ценой;
  3. если мата нет — сильные Stockfish-варианты сравниваются по атаке на короля, форсированности и материальной цене;
  4. добровольный пат/троекратное повторение фильтруются, если позиция не проиграна.
- В ответ `/api/coach/analyze` добавлен `master_insight`.
- Новые endpoints:
  - `/api/masters`
  - `/api/masters/status`
- Добавлен локальный сборщик мастерской библиотеки:
  `backend/scripts/build_master_library.py`.

## Важный принцип

Это **не нейросеть, обученная на именах шахматистов**. Мы строим прозрачный case-based тренер: партии превращаются в практические позиции, структуры и планы. Stockfish остаётся проверкой тактической корректности, а мастерские партии помогают объяснять практический план.

## Как реально наполнить библиотеку партиями

Из корня проекта:

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/build_master_library.py --players 45 --games-per-player 60 --positions-per-game 12
cd ..
```

После выполнения появится:

`backend/app/data/master_library/master_positions.json.gz`

Raw PGN в проект не сохраняются. В Git уходит только компактная библиотека извлечённых позиций.

Затем:

```bash
git add .
git commit -m "Add master games coach library"
git push
```

Render пересоберёт API и Coach начнёт использовать мастерскую практику.
